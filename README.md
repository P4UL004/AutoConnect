# AutoConnect

Projeto de gestão inteligente de vendas e serviços de veículos.
Trabalho da disciplina de Engenharia de Requisitos.

## Tecnologias

| Parte | Tecnologia |
|---|---|
| Backend | Java 25, Spring Boot 4.1.2 (Maven), Spring Security com JWT |
| Banco de dados | PostgreSQL 18 |
| Frontend | React (Vite) e Material UI |
